## Variant: Calm Authority

### Design stance
Editorial, content-first approach that builds trust through depth and precision — like Linear or Stripe. The portfolio leads with substance: case studies with real metrics, clear principles, and a tone that signals "I've done this before."

### Key choices
- **Layout**: Single-column, generous whitespace, clear hierarchy. Hero → metrics → case studies → principles → stack → testimonials → CTA.
- **Typography**: Space Grotesk for display (technical, distinctive), Inter for body (readable, neutral). High contrast scale.
- **Color**: Slate-950/900 for text, slate-50/100 for surfaces, blue-600 as sole accent. Restrained, professional.
- **Interaction**: Scroll-reveal animations (IntersectionObserver), card hover lift, button press states, smooth scroll nav. Subtle but alive.

### Trade-offs
- **Strong at**: Credibility, scan-ability, executive buyers, content-heavy storytelling
- **Weak at**: Immediate visual "wow," showing code/technical depth at a glance, younger developer audience

### Best for
- Enterprise decision-makers (VPE, CTO, Architect) who need confidence before a first call
- Consulting engagements where trust > flash
- Engineers who want to be taken seriously as architects, not just implementers
