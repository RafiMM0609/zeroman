## Variant: Technical Proof

### Design stance
Utilitarian, evidence-first approach that proves competence through code, architecture, and metrics — like GitHub or Vercel. Dark mode, monospace fonts, real code snippets, terminal aesthetic. The portfolio *is* the technical artifact.

### Key choices
- **Layout**: Dense, information-rich. Hero → live metrics → project cards with embedded code → stack as config file → principles as functions → testimonials as JSON.
- **Typography**: Space Grotesk for UI, JetBrains Mono for all technical content. Code blocks are first-class citizens.
- **Color**: Slate-950 background, cyan-400 as single accent (terminal green modernized), slate-800/700 for cards. High contrast, developer-native.
- **Interaction**: Card glow on hover, terminal cursor blink, scroll reveals, copyable code blocks (visual), smooth scroll. Feels like a well-crafted dev tool.

### Trade-offs
- **Strong at**: Technical buyers (Staff/Principal engineers, Architects), proving depth instantly, developer audience, SEO for technical keywords
- **Weak at**: Non-technical executives, visual "warmth," mobile scanning (dense), accessibility for non-devs

### Best for
- Technical decision-makers who read code before hiring
- Engineers building their reputation among peers
- Consulting where the buyer *is* the implementer
- Anyone wanting to filter for "people who get it"
