## Variant: Bold Vision

### Design stance
Playful, forward-looking, AI-native aesthetic — like Anthropic or OpenAI's enterprise pages. Gradient accents, animated blobs, split layouts with illustrative SVGs, hover delight. The portfolio *feels* like the future of AI engineering.

### Key choices
- **Layout**: Split-screen project cards (visual left, content right, alternating). Hero with animated gradient blobs. Generous space, big type.
- **Typography**: Syne for display (expressive, geometric), DM Sans for body (friendly, readable). Gradient text for emphasis.
- **Color**: White/Slate-50 base, violet→pink→cyan gradient system as primary brand. Color-coded project accents (violet=fintech, cyan=healthcare, amber=fraud, emerald=platform).
- **Interaction**: Blob parallax on mouse move, card hover with gradient top-bar reveal, button ripple, stat badge hover, scroll reveals with spring easing, star ratings. Delight at every touch.

### Trade-offs
- **Strong at**: Emotional resonance, differentiation, forward-thinking buyers, speaking engagements, brand building
- **Weak at**: Dense technical scanning, conservative enterprises, accessibility (motion), performance on low-end devices

### Best for
- Building a *personal brand* that stands out in a sea of gray portfolios
- Attracting clients who value design thinking alongside engineering
- Speaking/consulting where "vibe" is part of the sell
- Engineers who want to be remembered, not just referenced
